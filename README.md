# IPTV for Firestick USA

The Next.js App Router serves device guides and WhatsApp support pages at https://iptvforfirestickusa.com.

Install with `corepack pnpm install --frozen-lockfile`, then run `corepack pnpm dev`. Optional public configuration is documented in `env.example`.

Run `corepack pnpm lint`, `corepack pnpm build` and `corepack pnpm type-check` before deploying. To inspect rendered editorial markup, run `corepack pnpm aio:check <url>`.
